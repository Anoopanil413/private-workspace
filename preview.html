FixS★ Recommended

Pop-up windows leak page titles to the taskbar

Windows that pages open (Gmail compose, login pop-ups) show the page title in the taskbar, and the taskbar is captured when you share your screen.

FixS★ Recommended

Downloads with the same name overwrite each other

Downloading two files called invoice.pdf silently replaces the first one.

FixS★ Recommended

Encrypt notes on disk

Notes are plain text in %APPDATA%\private-workspace. Any program running as you can read them. Windows DPAPI (via Electron safeStorage) locks them to your Windows account.
